All About String in C

C & Systems Programming Pramudita Ahmad Apr 21, 2026 3 min read

Emang ada String di C?

Di bahasa C, sebenarnya nggak ada tipe data string khusus seperti di bahasa tingkat tinggi lainnya.

Yang ada hanyalah sekumpulan karakter (char) yang disusun berurutan di dalam memory, alias character array.

Ciri Khas Utama String di C

Ciri paling penting dari string di C adalah selalu diakhiri dengan null terminator ('\0').

Karakter '\0' ini menjadi penanda batas akhir string. Tanpa null terminator, fungsi pembaca string tidak akan tahu kapan harus berhenti dan akan terus membaca alamat memory berikutnya sampai menemukan byte nol secara kebetulan atau menyebabkan program crash.

Sebagai contoh deklarasi berikut:

char str[] = "Halo";

Susunan fisiknya di memory komputer (berukuran 5 byte):

['H'] ['a'] ['l'] ['o'] ['\0']

Cara Membuat String

Ada dua pendekatan umum saat mendeklarasikan string di C:

1. Array of Char

char nama[] = "Pram";

Ukuran array dialokasikan di stack dan otomatis disesuaikan dengan panjang teks ditambah 1 byte untuk '\0'. Keuntungan utamanya: isi karakternya bisa dimodifikasi secara bebas.

2. Pointer

char *pesan = "Halo";

Variabel pesan adalah pointer yang menunjuk langsung ke string literal di memory segmen teks (read-only). Pendekatan ini fleksibel karena pointernya bisa diarahkan ke string lain kapan saja, tetapi isinya tidak boleh diubah. Jika kamu mencoba mengubah karakternya, OS akan melempar sinyal Segmentation Fault.

Perbedaan Array vs Pointer (Kapan Dipakai?)

char[] (Array)

  • Bisa dimodifikasi, isi karakter bisa diubah langsung kapan saja.
  • Disimpan di memory lokal (stack).
  • Ukuran array tetap sesuai deklarasi awal.

Cocok untuk:

  • Menerima input dari user lewat terminal.
  • Operasi manipulasi string (edit kata, formatting, concat).
  • Kasus yang memerlukan modifikasi isi data.
char nama[20];
fgets(nama, sizeof(nama), stdin);

char * (Pointer)

  • Tidak boleh dimodifikasi (read-only string literal).
  • Mereferensikan alamat string literal di memory teks.
  • Fleksibel karena variabel pointernya bisa digeser menunjuk teks lain.

Cocok untuk:

  • String konstan yang tidak akan pernah berubah.
  • Pesan error statis, label teks, atau parameter fungsi konstan.
  • Konfigurasi sederhana.
char *msg = "Hello World";

Intinya: Gunakan char[] kalau datanya bakal berubah atau butuh input user. Gunakan char * kalau datanya tetap konstan.

Manipulasi String dengan <string.h>

Karena string di C adalah array, kita tidak bisa memakai operator seperti tanda plus (+) untuk menggabungkan string atau operator sama dengan (==) untuk membandingkannya. Kita menggunakan fungsi bawaan dari library standar <string.h>.

Fungsi Kegunaan Contoh Pemakaian
strlen() Menghitung panjang string tanpa menghitung '\0' strlen("Kopi") menghasilkan 4
strcpy() Menyalin string sumber ke variabel tujuan strcpy(dest, src)
strcat() Menggabungkan dua string (concat) strcat(sapaan, nama)
strcmp() Membandingkan dua string (return 0 jika sama) strcmp(input, "admin")

Contoh Code Sederhana

#include <stdio.h>
#include <string.h>

int main(void) {
    char sapaan[30] = "Halo";
    char nama[] = "Pram";

    /* Menggabungkan string */
    strcat(sapaan, " ");
    strcat(sapaan, nama);

    printf("%s\n", sapaan);
    printf("Panjang stringnya: %zu\n", strlen(sapaan));

    return 0;
}

Output program:

Halo Pram Panjang stringnya: 9

Kapan Pakai Fungsi Apa? (Kasus Nyata)

Berikut beberapa skenario nyata dalam pengembangan software:

  1. Hitung panjang input user: Gunakan strlen(nama) untuk validasi panjang minimum atau maksimum password dan username.
  2. Copy data antar variabel: Gunakan strcpy(dest, src) untuk duplikasi data atau membuat backup salinan teks.
  3. Gabung string: Gunakan strcat(fullname, lastname) untuk merangkai format nama lengkap atau menyusun path file sistem.
  4. Bandingkan string: Gunakan strcmp(input, "admin") untuk autentikasi user, parsing CLI argument, atau pengecekan role.

Waspada Bahaya Buffer Overflow

Buffer overflow adalah masalah klasik namun sangat berbahaya di bahasa C. Masalah ini terjadi saat data yang disalin melebihi kapasitas array yang sudah dipersiapkan di memory.

Contoh kesalahan:

char str[5];
strcpy(str, "Hello World"); /* BAHAYA: 11 karakter disalin ke wadah ukuran 5! */

Dampak yang ditimbulkan:

  • Data di luar batas array tertimpa, merusak variabel lain di memory stack.
  • Aplikasi langsung crash dengan status Segmentation Fault.
  • Menimbulkan celah keamanan fatal (security vulnerability) yang bisa dieksploitasi untuk pengambilalihan hak akses program.

Solusi Pencegahan:

  • Selalu pastikan kapasitas buffer array mencukupi untuk seluruh karakter plus 1 byte null terminator.
  • Gunakan varian fungsi yang membatasi jumlah copy seperti strncpy(dest, src, sizeof(dest) - 1) atau snprintf().
  • Gunakan fgets() untuk membaca baris dari terminal, hindari fungsi kuno gets().

Kesimpulan

Bekerja dengan string di bahasa C memberikan pemahaman mendalam tentang bagaimana data teks sebenarnya disimpan di tingkat hardware:

  • String di C = array of karakter yang ditutup oleh '\0'.
  • Tidak ada tipe data string built-in bawaan compiler.
  • Semua manipulasi string membutuhkan fungsi bantuan dari <string.h>.
  • Developer wajib selalu sadar ukuran alokasi memory agar aman dari bahaya buffer overflow.

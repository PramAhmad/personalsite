All About String in C

C & Systems Programming Pramudita Ahmad Apr 21, 2026 3 min read

Emang ada String di C?

Di bahasa C, sebenarnya nggak ada tipe data string khusus seperti di bahasa tingkat tinggi lainnya.

Yang ada hanyalah sekumpulan karakter (char) yang disusun berurutan di dalam memory, alias character array.

Ciri Khas Utama String di C

Ciri paling penting dari string di C adalah selalu diakhiri dengan null terminator ('\0').

Karakter '\0' ini menjadi penanda batas akhir string. Tanpa null terminator, fungsi pembaca string tidak akan tahu kapan harus berhenti dan akan terus membaca alamat memory berikutnya sampai menemukan byte nol secara kebetulan atau menyebabkan program crash.

Sebagai contoh deklarasi berikut:

char str[] = "Halo";

Susunan fisiknya di memory komputer (berukuran 5 byte):

['H'] ['a'] ['l'] ['o'] ['\0']

Cara Membuat String

Ada dua pendekatan umum saat mendeklarasikan string di C:

1. Array of Char

char nama[] = "Pram";

Ukuran array dialokasikan di stack dan otomatis disesuaikan dengan panjang teks ditambah 1 byte untuk '\0'. Keuntungan utamanya: isi karakternya bisa dimodifikasi secara bebas.

2. Pointer

char *pesan = "Halo";

Variabel pesan adalah pointer yang menunjuk langsung ke string literal di memory segmen teks (read-only). Pendekatan ini fleksibel karena pointernya bisa diarahkan ke string lain kapan saja, tetapi isinya tidak boleh diubah. Jika kamu mencoba mengubah karakternya, OS akan melempar sinyal Segmentation Fault.

Perbedaan Array vs Pointer (Kapan Dipakai?)

char[] (Array)

  • Bisa dimodifikasi, isi karakter bisa diubah langsung kapan saja.
  • Disimpan di memory lokal (stack).
  • Ukuran array tetap sesuai deklarasi awal.

Cocok untuk:

  • Menerima input dari user lewat terminal.
  • Operasi manipulasi string (edit kata, formatting, concat).
  • Kasus yang memerlukan modifikasi isi data.
char nama[20];
fgets(nama, sizeof(nama), stdin);

char * (Pointer)

  • Tidak boleh dimodifikasi (read-only string literal).
  • Mereferensikan alamat string literal di memory teks.
  • Fleksibel karena variabel pointernya bisa digeser menunjuk teks lain.

Cocok untuk:

  • String konstan yang tidak akan pernah berubah.
  • Pesan error statis, label teks, atau parameter fungsi konstan.
  • Konfigurasi sederhana.
char *msg = "Hello World";

Intinya: Gunakan char[] kalau datanya bakal berubah atau butuh input user. Gunakan char * kalau datanya tetap konstan.

Manipulasi String dengan <string.h>

Karena string di C adalah array, kita tidak bisa memakai operator matematika seperti tanda tambah (+) untuk menggabungkan string atau operator kesetaraan (==) untuk membandingkannya. Kita menggunakan fungsi bawaan dari library standar <string.h>.

Fungsi Kegunaan Contoh Pemakaian
strlen() Menghitung panjang string tanpa menghitung '\0' strlen("Kopi") menghasilkan 4
strcpy() Menyalin string sumber ke variabel tujuan strcpy(dest, src)
strcat() Menggabungkan dua string (concat) strcat(sapaan, nama)
strcmp() Membandingkan dua string (return 0 jika sama persis) strcmp(input, "admin")

Contoh Program Sederhana

#include <stdio.h>
#include <string.h>

int main(void) {
    char sapaan[30] = "Halo";
    char nama[] = "Pram";

    /* Menggabungkan string */
    strcat(sapaan, " ");
    strcat(sapaan, nama);

    printf("%s\n", sapaan);
    printf("Panjang stringnya: %zu\n", strlen(sapaan));

    return 0;
}

Output program:

Halo Pram Panjang stringnya: 9

Kapan Pakai Fungsi Apa? (Kasus Nyata)

Berikut beberapa skenario nyata dalam pengembangan software:

  1. Hitung panjang input user: Gunakan strlen(nama) untuk validasi batas minimal atau maksimal username dan password.
  2. Copy data antar variabel: Gunakan strcpy(dest, src) untuk duplikasi data atau membuat backup salinan teks.
  3. Gabung string: Gunakan strcat(fullname, lastname) untuk merangkai format nama lengkap atau menyusun path file sistem.
  4. Bandingkan string: Gunakan strcmp(input, "admin") untuk autentikasi user, parsing CLI argument, atau pengecekan role.

Waspada Bahaya Buffer Overflow

Buffer overflow adalah masalah klasik yang sangat berbahaya di bahasa C. Masalah ini terjadi saat data yang disalin melebihi kapasitas array yang sudah dipersiapkan di memory.

Contoh kesalahan:

char str[5];
strcpy(str, "Hello World"); /* BAHAYA: 11 karakter disalin ke wadah ukuran 5! */

Dampak yang ditimbulkan:

  • Data di luar batas array tertimpa, merusak variabel lain di memory stack.
  • Aplikasi langsung crash dengan status Segmentation Fault.
  • Menimbulkan celah keamanan fatal yang bisa dieksploitasi untuk pengambilalihan kontrol program.

Solusi Pencegahan:

  • Selalu pastikan kapasitas buffer array mencukupi untuk seluruh karakter plus 1 byte null terminator.
  • Gunakan varian fungsi yang membatasi jumlah copy seperti strncpy(dest, src, sizeof(dest) - 1) atau snprintf().
  • Gunakan fgets() untuk membaca baris dari terminal, hindari fungsi kuno gets().

Kesimpulan

Bekerja dengan string di bahasa C memberikan pemahaman mendalam tentang bagaimana data teks sebenarnya disimpan di tingkat hardware:

  • String di C adalah array of karakter yang wajib ditutup oleh '\0'.
  • Tidak ada tipe data string built-in bawaan compiler.
  • Semua manipulasi string membutuhkan fungsi bantuan dari <string.h>.
  • Developer wajib selalu sadar ukuran alokasi memory agar aman dari bahaya buffer overflow.

Is There Really a String in C?

In C, there is no dedicated string data type like in Python, JavaScript, or Java.

Instead, a string is simply a sequence of characters (char) laid out contiguously in memory, known as a character array.

The Core Rule: Null Terminator

Every valid string in C must end with a special byte called the null terminator ('\0').

The '\0' character acts as a sentinel boundary. Without it, string reading functions have no idea where your text ends and will keep reading adjacent memory bytes until they happen upon a random zero byte or cause a segmentation fault.

Consider this declaration:

char str[] = "Halo";

Here is how it is structured physically in computer memory (5 bytes total):

['H'] ['a'] ['l'] ['o'] ['\0']

How to Create Strings in C

There are two primary ways to declare strings in C:

1. Array of Char

char name[] = "Pram";

The array size is allocated on the stack and automatically fits the length of the text plus 1 byte for '\0'. The main advantage is that its contents are completely mutable.

2. Pointer

char *msg = "Halo";

The variable msg is a pointer pointing directly to a string literal in the read-only text segment of memory. This approach is flexible because the pointer can be redirected to another string at any time, but its contents must never be modified. Attempting to write into it will trigger a Segmentation Fault.

Array vs Pointer (When to Use Which?)

char[] (Array)

  • Mutable, you can modify any character in place.
  • Stored in local stack memory.
  • Fixed size determined at declaration.

Best for:

  • Reading user input from the terminal.
  • String manipulation routines (edits, concatenation, formatting).
  • Any scenario where data needs to change dynamically.
char name[20];
fgets(name, sizeof(name), stdin);

char * (Pointer)

  • Immutable (points to a read-only string literal).
  • Only stores the memory address of the string.
  • Flexible because the pointer variable can be reassigned to other addresses.

Best for:

  • Constant strings that never change during execution.
  • Static status messages, UI labels, or constant function parameters.
  • Simple configuration constants.
char *msg = "Hello World";

Rule of thumb: Use char[] when data will be edited or needs user input. Use char * when the text is constant.

String Manipulation with <string.h>

Because strings in C are raw arrays, you cannot use operators like + to join strings or == to compare them. Instead, C provides utility functions in the standard library <string.h>.

Function Purpose Example Usage
strlen() Calculates string length excluding '\0' strlen("Coffee") returns 6
strcpy() Copies source string into destination buffer strcpy(dest, src)
strcat() Appends source string to destination (concatenate) strcat(greeting, name)
strcmp() Compares two strings lexicographically (returns 0 if equal) strcmp(input, "admin")

Simple Code Example

#include <stdio.h>
#include <string.h>

int main(void) {
    char greeting[30] = "Halo";
    char name[] = "Pram";

    /* Concatenate strings */
    strcat(greeting, " ");
    strcat(greeting, name);

    printf("%s\n", greeting);
    printf("String length: %zu\n", strlen(greeting));

    return 0;
}

Program output:

Halo Pram String length: 9

When to Use Which Function? (Real-World Cases)

Common practical scenarios in software engineering:

  1. Validating user input length: Use strlen(name) to check minimum and maximum boundaries for usernames and passwords.
  2. Copying data between buffers: Use strcpy(dest, src) when creating duplicate records or data backups.
  3. Joining strings: Use strcat(path, filename) to build filesystem directory paths or format full names.
  4. Comparing strings: Use strcmp(input, "admin") for CLI flag parsing, command dispatching, or role verification.

Watch Out for Buffer Overflow!

Buffer overflow is a classic vulnerability in C programming. It occurs when you write more bytes into an array than the memory buffer was allocated to hold.

A dangerous example:

char str[5];
strcpy(str, "Hello World"); /* DANGER: 11 bytes forced into a 5-byte buffer! */

Consequences of buffer overflow:

  • Overwriting adjacent stack memory and corrupting unrelated variables.
  • Immediate application crashes with Segmentation Fault.
  • Severe security vulnerabilities that attackers can exploit to execute arbitrary code.

Prevention Best Practices:

  • Always allocate enough space for all characters plus 1 extra byte for the null terminator.
  • Use bounded functions like strncpy(dest, src, sizeof(dest) - 1) or snprintf() instead of unbounded strcpy().
  • Use fgets() for reading user input from standard input, and never use obsolete functions like gets().

Summary

Working with strings in C provides a clear understanding of how computer hardware actually represents text data:

  • A string in C is a character array terminated by '\0'.
  • There is no built-in primitive string type in the compiler.
  • All string manipulation relies on functions from <string.h>.
  • Always stay aware of buffer sizes and memory boundaries to keep your code safe and crash-free.
